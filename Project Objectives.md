##### **Objectives**

##### **1.	Simulate a realistic multi-card ATM: create accounts, authenticate, 	and perform banking operations.**

##### **2.	Keep each card’s data isolated (balance, PIN, mini-statement) while 	sharing one ATM controller.**

##### **3.	Persist all cards across program restarts using a structured JSON 	file.**

##### **4.	Enforce simple security rules: 4-digit PIN, three login attempts, 	masked card numbers, and confirmation 	before delete.**

##### **5.	Provide a clear, menu-driven interface suitable for demonstration and 	evaluation.**
